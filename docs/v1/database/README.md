# V1 Database Model

This folder contains the database model for V1 of the Feature Flag Platform.

## Goal

Define a pragmatic relational model aligned with:

- Domain model
- Aggregate boundaries
- Sequence diagrams

## Design Principles

- Multi-tenant by workspace
- UUID identifiers
- Immutable audit history
- Simple relational model
- No premature optimization

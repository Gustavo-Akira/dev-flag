# UC-02 — Invite Workspace Member

## Objective
Invite users to collaborate in a workspace.

## Roles
- OWNER
- ADMIN
- DEVELOPER
- VIEWER

## Main Flow
1. User opens workspace members page.
2. Adds member email.
3. Selects role.
4. System sends invite.
5. User joins workspace.

## Business Rules
- Only OWNER or ADMIN can invite.

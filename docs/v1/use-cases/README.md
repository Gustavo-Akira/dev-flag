# Feature Flag Platform - Use Cases (V1)

## Goal

Deliver a pragmatic feature flag platform with production-like fundamentals.

## Domain Flow

Workspace
└── Project
    └── Environment
        └── Feature Flag

## Included in V1

- Workspace management
- Project management
- Default environments
- Boolean feature flags
- Rollout percentage
- User targeting (allowlist)
- Audit log
- SDK evaluation endpoint
